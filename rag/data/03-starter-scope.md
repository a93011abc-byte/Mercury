# 入門程式的範圍

這個 RAG 入門程式在本機執行。預設生成器不需要 API 金鑰，也不會連外網。

## 預設如何回答

預設路徑不會呼叫任何外部模型。它只摘錄檢索到的片段原文，並在每一段摘錄前標上片段編號，例如 `03-starter-scope.md#0`。若沒有檢索到相關片段，程式會拒絕回答，並說明目前的語料庫無法支持這個問題的答案。程式不會編造文件裡沒有的內容。

## 選用的外部模型

只有在環境變數 `RAG_LLM_ENABLED=1`，而且另外提供 OpenAI 相容介面的網址、金鑰與模型名稱時，才會改走外部生成器。這條路徑預設關閉。外部模型仍然只能根據檢索到的片段作答，並且要引用片段編號。

## 目前沒有做的事

此版本沒有混合檢索，也沒有重排序。沒有身分驗證。索引更新不是增量的：每次 ingest 都會重建整份 `index/store.json`。
